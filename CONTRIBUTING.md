# Contributing to RP UI Kit

Спасибо за желание помочь! Проект сознательно простой: ноль зависимостей, ноль сборки.
Умеешь открыть DevTools - умеешь контрибьютить.

## Быстрый старт

```bash
git clone https://github.com/hilsetapp/Gtarp-ui-kit.git
cd rp-ui-kit
python3 -m http.server 8000   # или открой index.html напрямую
```

Меняй, перегружай, проверяй в песочнице. Перед PR:

```bash
node --check kit/rp-ui-kit.js
```

И обязательно глазами: каждый компонент должен работать в браузерном демо-режиме
(алерты в консоли `[RPUI] ...`), иначе в игре будет боль.

## Железные правила

1. **Ноль зависимостей.** Ни npm-пакетов, ни фреймворков, ни билд-шагов -
   вечно: `rp-ui-kit.js` и `rp-ui-kit.css`, копируются руками.
2. **Совместимость с CEF.** RAGE MP живёт на старом Chromium -
   синтаксис не новее ES2019, CSS без `:has()`, `@container`, `gap` в старых местах проверять.
3. **События - только через мост.** Любой сигнал наружу - `emit("component:action", data)`,
   свойства в snake: `{ from: 3 }`. Префикса `rpui:` добавляет сам мост.
4. **Инвариант темы.** Никаких хардкод-цветов в компонентах - только CSS-переменные (`--rpui-*`).
5. **Браузерный демо-режим не должен ломаться.** Страница обязана жить без `mp`/`alt`.

## Где твоя помощь особенно ценна

- Компоненты из README-roadmap: регистрация персонажа, миникарта, тосты.
- Иконки предметов в едином стиле (SVG-набор для инвентаря).
- Примеры интеграции в конкретные гейммоды (RedAge и др.) - отдельной папкой `examples/`.
- Переводы интерфейса (компонент тексты сейчас по-русски по умолчанию - i18n-слой в v0.2).

## Стиль коммитов

Коротко и в императиве: `add toast component`, `fix inventory swap on empty slot`.

Контрибьюцией ты соглашаешься на лицензию [MIT](LICENSE).
