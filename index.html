engine-free zero build MIT github ★
«игровой экран» — так это увидит игрок

Подключение за 4 шага

Скопируй kit/rp-ui-kit.js и kit/rp-ui-kit.css в CEF-папку твоего проекта и подключи на странице. Адаптер сам определит движок (mp.trigger из RAGE MP, alt.emit из alt:V) — в браузере включается демо-режим, события видно в консоли.

① index.html твоего CEF 
<link rel="stylesheet" href="rp-ui-kit.css">
<script src="rp-ui-kit.js"></script>
<script>
  // входящие от сервера события:
  RPUI.on("hud:update", d => window.hud && hud.update(d));
</script>
② RAGE MP — клиентская часть (client_packages/*.js) 
// сервер шлёт в браузер:
browser.call("RPUI.receive", JSON.stringify({
  ev: "hud:update",
  data: { speed: player.vehicle.velocity.length() * 3.6 }
}));
// ответы из интерфейса приходят в mp.events:
mp.events.add("rpui:inventory:use", (json) => {
  const { data } = JSON.parse(json);
  mp.gui.chat.push(`игрок хочет использовать предмет в слоте ${data.slot}`);
});
③ alt:V — клиентская часть 
webView.emit("RPUI.receive", "hud:update", { speed: 120 });
alt.on("rpui:inventory:use", ({ data }) => alt.log("use", data.slot));
④ Тема под цвет сервера 
:root { --rpui-accent: #4da6ff; }  /* один цвет — все компоненты ваши */
→ перетаскивай ячейки, правый клик — действия
→ поле ввода снизу слева тоже живое
→ СМС, банк, заметки, тема уже внутри

⚡ лентa событий (RPUI.on("*"))
